# Проморолик мобильной главной

15 секунд, 16:9, 1920 × 1080, 30 fps, MP4 до 20 МБ. Сценарий подтверждён автором в чате 23.11.2026; готовый ролик ожидает просмотра.

Путь: главная с сохранённым поиском → выдача двухкомнатных квартир в Сокольниках до 20 млн ₽ → карточка квартиры → финальный призыв «Начните с главной».

Экраны сняты из текущей React-сборки реальными переходами, 390 × 844 при плотности 2×. Интерфейс не перерисован. Титры, обрамление, подсветка нажатий и движение камеры добавлены для ролика. Данные объявлений — существующие синтетические данные прототипа. Озвучки нет; инструментальная музыка синтезирована как черновая подложка.
