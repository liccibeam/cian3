# Как устроен прототип

## Маршруты и состояние

| Маршрут        | Назначение                                               |
| -------------- | -------------------------------------------------------- |
| `/`            | Главная, поиск и рекомендации                            |
| `/search`      | Выдача, фильтры и сортировка                             |
| `/listing/:id` | Галерея, характеристики и локальная форма связи          |
| `/ui`          | Каталог общего UI-kit                                    |
| `/patterns`    | Компоненты страниц и ссылки на состояния                 |
| `/guide`       | Краткое руководство дизайнера                            |
| `/map`         | Карта мобильного сценария, цели Метрики и план A/B-теста |

`src/data/listings.ts` содержит тип `Listing`, восемь синтетических объявлений и чистую функцию фильтрации. Поиск — подстрока по названию, адресу, району и метро, а не семантический AI-поиск. Цены и площади демонстрационные. Фотографии взяты как визуальные референсы и не описывают синтетические объявления; кадры одной демонстрационной галереи могут относиться к разным объектам.

Параметры `q`, `rooms`, `maxPrice`, `sort`, `favorites=1` хранятся в URL. Пустая комнатность означает любую, `0` — студию. Сортировка: `default`, `price-asc`, `price-desc`, `area-desc`. Кнопка возврата из карточки сохраняет исходную главную или URL выдачи и позицию прокрутки; прямой вход в карточку возвращает к общему поиску. Back в браузере также восстанавливает прокрутку, в том числе после загрузки выдачи.

`PrototypeProvider` хранит избранное в `localStorage` (`cian3:favorites:v1`), а последний и сохранённые поиски — в `cian3:searches:v1`. Контекст предоставляет `rememberSearch(params)`, `saveSearch(params)` и `removeSearch(search)`, а также `showDemo(title)` для незапроектированных разделов и `notify(text)` для статуса действий. Поиски нормализуются по `q`, `rooms`, `maxPrice`, `sort`; одинаковые параметры не дублируются. Избранное и принудительные состояния выдачи в историю не попадают. Недоступный или повреждённый storage не мешает работе текущей сессии. Реальной отправки сообщений, авторизации или запросов к API Циана нет. Цели Метрики размечены с номером-заглушкой `0`; без счётчика они попадают только в локальный журнал. Подробнее — [карта и аналитика](home-scenario.md).

На ширине до 760 px главная использует новую композицию, а главная, выдача и карточка — общий мобильный каркас: компактная шапка и нижняя навигация. Десктопная композиция сохранена. Детали решения и снимки — в [описании мобильной главной](home-mobile.md).

Переход в пустую `/search` через таббар, категорию или ссылку «Все объявления» не заменяет последний запрос. Явная отправка пустого поиска, применение очищенных фильтров или их сброс сохраняют поиск по всей Москве. Прямая ссылка с критериями также восстанавливает их в истории.

## Композиции

| Компонент        | Использование                                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `AppShell`       | Header + содержимое + Footer; `mobileApp` включает мобильную шапку и таббар до 760 px                                             |
| `PageLayout`     | Контейнер с `children` и необязательным `aside`; на телефоне одна колонка                                                         |
| `Breadcrumbs`    | `items: {label,to?}[]`                                                                                                            |
| `ListingCard`    | `listing: Listing`, `compact?: boolean`, `feed?: boolean`; `feed` адаптирует компактную карточку для двух колонок мобильной ленты |
| `SearchBar`      | Поиск с главной                                                                                                                   |
| `SearchFilters`  | `params: URLSearchParams`, `onApply(next)`                                                                                        |
| `Sorting`        | `value`, `onChange(value)`                                                                                                        |
| `Gallery`        | `images`, `title`; выбор кадра и диалог просмотра                                                                                 |
| `ListingActions` | `listing`; цена, продавец и локальная форма                                                                                       |
| `PrototypePage`  | Шаблон нового сценария с `title`, `description?`, `children`, `aside?`                                                            |

## Проверка состояний

- `/?scenario=new` — мобильная главная нового пользователя без истории.
- `/?scenario=returning` — мобильная главная с сохранённым поиском: 2-комнатная квартира в Сокольниках до 20 млн ₽.
- `/?scenario=recent` — главная только с последним поиском.
- `/search?favorites=1&scenario=favorites` — изолированное заполненное избранное.
- `/?scenario=returning&panel=saved` — открытый список сохранённых поисков.
- `/listing/1?scenario=new&panel=gallery` — галерея; `panel=contact` — форма связи; `panel=sent` — локальное подтверждение.
- `/?scenario=new&panel=demo` — демонстрационное окно незапроектированного раздела.
- `/search?state=loading` — постоянный skeleton для ревью.
- `/search?state=empty` — пустая выдача.
- `/search?q=Сокольники&state=error` — ошибка; повторная попытка сохраняет фильтры.
- `/search?q=НесуществующийРайон` — естественная пустая выдача.
- `/search?favorites=1` — пустое или заполненное избранное.
- `/listing/unknown` — неизвестное объявление.

Обычная выдача использует небольшую демонстрационную задержку 280 мс. Маршрут `/patterns` даёт доступ ко всем состояниям без редактирования кода. Ссылки на примеры главной выполняют полную загрузку: отдельный пример действует до следующей полной загрузки страницы; его поиски и избранное живут только в памяти и не перезаписывают личные данные. Для выхода используйте ссылку «Главная с моими данными» в `/patterns` или загрузите `/` заново без `scenario`.

## Границы готовности

Это основа для новых кликабельных сценариев. Карта, ипотека, личный кабинет, размещение объявления, сравнение и серверная отправка не реализованы. Они дают локальный демонстрационный ответ. Задание участников (например, размещение или новый тип объявления) не решено заранее. Базовое приложение светлое; тёмный режим проверяется в каталоге UI-kit.
