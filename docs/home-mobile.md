# Мобильная главная

Решение задачи `tasks/home-mobile`: новая композиция приложения поверх существующей React-основы. Локальный прототип, данные синтетические. Основной размер — 390 × 844, мобильная версия включается до 760 px. Десктоп сохраняет прежнюю главную.

## Композиция и поведение

Компактная шапка с Москвой → поиск → пять направлений → один блок продолжения поиска (если есть история) → рекомендации. Большой фотофон и блок сервисов уступили место объявлениям. Узнаваемость поддерживают логотип, Lato, исходные токены и компоненты Циана.

«Купить» и поиск ведут в существующую выдачу квартир. «Снять», «Новостройки», «Посуточно», «Коммерческая», реклама, сообщения и профиль открывают демонстрационные окна с названием выбранного сценария. Другие вертикали и личный кабинет не реализуются.

В ленте восемь существующих объявлений без повторов; после четвёртого — рекламное размещение с маркировкой. Избранное общее для главной, выдачи и карточки. Рекомендации фиксированы: наличие истории меняет блок продолжения, а не выдаёт имитацию алгоритмической персонализации.

Сохранённый поиск имеет приоритет перед последним. На главной показывается один, последний сохранённый вариант; остальные доступны по кнопке «Все». В выдаче можно сохранить текущие параметры без дубликатов. Из списка можно удалить поиск; после удаления последнего главная предлагает недавний. История сохраняется локально, без авторизации; избранное не перезаписывает последний поиск.

Обычная навигация в «Поиск» или «Все объявления» сохраняет последний запрос. Поиск по всей Москве записывается в историю при явной отправке пустой формы или применении/сбросе очищенных фильтров.

Нижняя навигация общая для главной, выдачи и карточки. Из карточки можно вернуться на исходную главную или в выдачу с параметрами и позицией прокрутки. Работающие пути доступны также клавиатурой; диалоги закрываются по Escape.

## Просмотр

Запуск: `npm ci`, затем `npm run dev`. Открыть мобильный viewport браузера.

| Адрес                  | Состояние                                             |
| ---------------------- | ----------------------------------------------------- |
| `/`                    | Реальные локальные данные этого браузера              |
| `/?scenario=new`       | Новый пользователь без истории                        |
| `/?scenario=returning` | Возвращающийся с сохранённым поиском                  |
| `/patterns`            | Каталог состояний и выход из примеров к личным данным |

Примеры изолированы на время страницы: можно проходить поиск, сохранять и удалять запросы, добавлять избранное; личное хранилище при этом не меняется. После полной загрузки другого адреса действует обычный режим. `scenario` — инструмент просмотра, в продуктовой главной переключателя нет.

## Визуальные источники и проверка

Оформление опирается на `docs/references/home-mobile.jpg` от 16.11.2026 и UI-kit от 12.11.2026. Референс — мобильный сайт; новая композиция — адаптация под задачу приложения, с рекламой ниже первых четырёх рекомендаций. Исходный снимок в `public/reference/` не изменён.

На ширинах 390 и 360 px проверяются оба состояния: заголовок рекомендаций, первые фотографии и цены должны находиться выше таббара без прокрутки; горизонтального переполнения быть не должно. На 1440 px проверяется исходная десктопная композиция. Снимки после проверки:

- [Новый пользователь, 390 × 844](home-mobile-new.png)
- [Возвращающийся, 390 × 844](home-mobile-returning.png)

Проверено 23.11.2026: оба состояния на ширинах 390 и 360 px проходят критерии первого экрана и не дают горизонтального переполнения; на 1440 px сохраняется десктопная композиция. В мобильном viewport 390 × 844 нижняя граница первой цены — 622 px у нового пользователя и 740 px у возвращающегося (округление вверх), верх таббара — 779 px.

В браузере пройдены поиск через Tab/Enter, сохранение после перезагрузки, избранное, удаление поиска и возврат фокуса после Escape, демонстрационные окна, длинная подпись и восстановление после ошибки/пустой выдачи. Возврат из карточки на главную восстановил прокрутку 600 px; отдельно проверен возврат в выдачу после её загрузки.

Первоначальные `npm run typecheck`, `npm run lint`, `npm test` и `npm run build` завершились успешно (19 тестов). После независимого ревью добавлены ещё два регрессионных теста и уточнена проверка пустой отправки: навигация не должна стирать прошлый запрос, явная очистка должна сохраняться. Подробности — в [отчёте ревью](home-mobile-review.md).

Повторные проверки после исправления: `typecheck`, `lint`, `build` успешны, все 21 тест проходят.

Прохождение проверок подтверждает работу прототипа; принятие решения автором и влияние на продуктовые метрики требуют отдельной оценки.
